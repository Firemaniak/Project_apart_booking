# StayHome — платформа бронирования жилья

Полноценная платформа краткосрочной аренды жилья для рынка Германии. Гости могут искать, фильтровать и бронировать проверенные объявления; хозяева — размещать, редактировать и отслеживать эффективность своих объектов.

## Возможности

**Для гостей**
- Каталог объявлений с поиском, фильтром по цене и сортировкой по популярности
- Интерактивная карта с местоположением объявления
- Бронирование по датам с живым календарём доступности
- Симуляция оплаты картой с подтверждением на email
- Отзывы после завершённого проживания
- Избранное
- Публичные профили хозяев с рейтингом

**Для хозяев**
- Создание и редактирование объявлений с галереей фото
- Указание точного местоположения на карте (с гео- и обратным геокодированием)
- Включение/скрытие объявления без удаления
- Публичные ответы на отзывы гостей
- Статистика по каждому объявлению: просмотры, брони, выручка, средний рейтинг
- Личная статистика: заработано, потрачено, объявления, брони, рейтинг

**Платформа**
- JWT-авторизация (email + пароль)
- Мультиязычный интерфейс: русский, английский, немецкий, украинский
- История поиска и учёт просмотров по каждому объявлению
- Мягкое удаление аккаунтов (без потери данных)
- Полная история изменений ключевых моделей (через `django-simple-history`)
- Swagger/OpenAPI документация по всему API

## Технологии

- **Бэкенд:** Django, Django REST Framework, SimpleJWT
- **База данных:** MySQL 8.4
- **Фронтенд:** чистый HTML/CSS/JavaScript (без фреймворков), Leaflet.js для карт, Flatpickr для выбора дат
- **Инфраструктура:** Docker, Docker Compose
- **Документация:** drf-yasg (Swagger UI)

## Запуск локально через Docker

1. Клонируй репозиторий:
```bash
   git clone https://github.com/Firemaniak/Project_apart_booking.git
   cd Project_apart_booking
```

2. Создай файл `.env` в корне проекта:

SECRET_KEY=твой-секретный-ключ
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

DATABASE_ENGINE=mysql
DB_NAME=apart_booking
DB_USER=apart_booking_user
DB_PASSWORD=твой-пароль
DB_ROOT_PASSWORD=твой-рут-пароль
DB_HOST=db
DB_PORT=3306


3. Собери и запусти контейнеры:
```bash
   docker compose up -d --build
```

4. Создай суперюзера:
```bash
   docker compose exec web python manage.py createsuperuser
```

5. (Опционально) Наполни базу тестовыми объявлениями:
```bash
   docker compose exec web python manage.py seed_data --count 30
```

6. Открой приложение:
   - Фронтенд: `http://localhost:8000/`
   - Админка: `http://localhost:8000/admin/`
   - Документация API: `http://localhost:8000/swagger/`

## Тестовый аккаунт

После запуска `seed_data` автоматически создаётся тестовый хозяин:
- **Email:** `test_owner@example.com`
- **Пароль:** `testpass123`

## Обзор API

Полная интерактивная документация доступна по адресу `/swagger/`. Основные группы эндпоинтов:

| Эндпоинт | Описание |
|---|---|
| `/api/users/` | Регистрация, вход (JWT), профиль |
| `/api/listings/` | Объявления, фото, избранное |
| `/api/bookings/` | Брони, оплата, доступность |
| `/api/reviews/` | Отзывы и ответы хозяев |
| `/api/statistics/` | Статистика объявлений и юзеров, популярные запросы |
